OUTPUT/REPORTS — Data Quality Reports Directory
================================================

Report files saved here are generated automatically by the pipeline.
They help you understand the quality of your input data.

FILES CREATED BY THE PIPELINE
───────────────────────────────
(Created automatically after pipeline runs)

  preprocessing_summary.csv   ← Summary of the data cleaning step.
                                 Tells you:
                                 - How many rows were in the original file
                                 - How many duplicates were removed
                                 - How many rows had bad/unparseable dates
                                 - How many rows made it into the database
                                 - Data completeness percentage

THESE REPORTS ARE NOT USED BY POWER BI
────────────────────────────────────────
These are internal quality reports for the developer.
They help you verify that the pipeline is working correctly
and that data quality is acceptable.

For your project report, you can reference these numbers to show
that you performed proper data validation and cleaning.
